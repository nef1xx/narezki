# Cliproom

Локальное приложение для нарезки стримов на вертикальные клипы с рекламной вставкой. Интерфейс в браузере, обработка через FFmpeg, сервер на стандартной библиотеке Python. Видео читаются прямо с диска: загрузки в облако и копирования исходника нет.

## Запуск на Windows

1. Дважды нажмите **start.bat**. Нужен установленный Python 3.9 или новее.
2. При первом запуске приложение скачает переносимый FFmpeg в `.tools` и сверит SHA-256. Если FFmpeg и FFprobe уже есть в PATH, скачивание не требуется.
3. Откроется **http://127.0.0.1:8765**. Оставьте окно сервера открытым на время работы. Для остановки нажмите Ctrl+C в этом окне.

Можно запустить вручную:

```powershell
python app.py --open
```

Если порт занят:

```powershell
python app.py --port 8766 --open
```

## Работа

1. Выберите исходное видео. Если диалог не открывается, раскройте «Открыть по пути к файлу» и вставьте полный путь.
2. Выберите рекламный ролик. Приложение запоминает его расположение; держите этот файл на прежнем месте.
3. Нажмите «Вебка» и обведите область лица на кадре. Затем нажмите «Контент» и выделите нужную область. Предполагается, что вебка уже находится внутри исходного видео, а её позиция постоянна.
4. При необходимости выберите другой кадр ползунком. Координаты также можно задать числами, без мыши.
5. Настройте высоту вебки и режимы: **crop** заполняет область с обрезкой по центру; **fit** сохраняет всю выделенную область, добавляя чёрные поля.
6. Выберите разрешение и скорость. По умолчанию — 720 × 1280, 30 кадров/с, быстрый CPU-экспорт. Режим «Максимально быстро» создаёт более объёмные файлы.
7. При желании нажмите «Проверить видео со звуком»: приложение создаст короткий образец с настоящей рекламной вставкой. Это действие запускается только пользователем.
8. Нажмите «Создать клипы». Результаты появятся в отдельной папке внутри `exports` либо выбранной вами папки. Их можно воспроизвести, скачать или открыть в Проводнике.

## Длительность и реклама

- Каждая полная часть содержит **60 секунд исходного видео**, а реклама добавляется сверх этой минуты.
- Например, баннер на 8 секунд даёт клип **30 секунд исходника → 8 секунд рекламы → 30 секунд исходника = 68 секунд**.
- На рекламе исходное видео и исходный звук не проигрываются. Продолжение начинается с того же места, где закончилась первая половина.
- Последняя часть содержит остаток; реклама встаёт в его середину. На границах возможна дискретность в один кадр (1/30 секунды).
- Реклама накладывается поверх стоп-кадра в нижней части видео, сохраняя свой звук. В режиме «Вписать целиком» вокруг баннера видно исходный кадр, без добавленных чёрных полей. Режим заполнения обрезает баннер до его области. Отсутствующая аудиодорожка заменяется тишиной.
- Между вебкой и контентом можно добавить две строки текста: белую и жёлтую, с наклоном, обводкой и тенью. Размер регулируется; пустые строки скрываются. Текст сохраняется в настройках и присутствует в предпросмотре и экспорте, в том числе во время рекламы.
- Результат: MP4, H.264, yuv420p, AAC stereo 48 кГц, faststart.

## Хранение и ограничения MVP

- `data/settings.json`: баннер, расположение экспорта и настройки компоновки.
- `data/frames`: уменьшенные кадры для редактора; `data/previews`: пробные ролики. Их можно удалить при закрытом приложении.
- В каждой папке экспорта находятся ролики, параметры проекта и журнал FFmpeg. Исходные файлы не изменяются.
- Одновременно выполняется один экспорт. Кнопка остановки сохраняет уже готовые клипы и удаляет незаконченный файл текущей части.
- Список заданий хранится до перезапуска сервера. Экспортированные файлы остаются на диске. Автоматического возобновления прерванной очереди пока нет.
- Настройки областей постоянны на всём видео: автоматического отслеживания лица, определения сцен и отдельного источника вебки в MVP нет.
- Скорость зависит от разрешения исходника, процессора и диска. Аппаратное кодирование GPU пока не добавлено.
- Интернет требуется только для первоначального скачивания FFmpeg. Сервер слушает только `127.0.0.1`.

Сборка FFmpeg: [Gyan](https://www.gyan.dev/ffmpeg/builds/), указана на [странице загрузки FFmpeg](https://ffmpeg.org/download.html). Принцип обработки: [фильтры FFmpeg](https://ffmpeg.org/ffmpeg-filters.html).

Для обновления с текстом и наложением баннера проверены синтаксис Python/JavaScript, интерфейс в браузере на широком и узком экране, а также короткие экспорты 720p и 1080p, включая остаток в один кадр.
