# Cliproom

Локальное приложение для нарезки стримов на вертикальные клипы с рекламной вставкой. Интерфейс в браузере, обработка через FFmpeg, сервер на стандартной библиотеке Python. Видео читаются прямо с диска: загрузки в облако и копирования исходника нет.

Разработчик: [nef1xx](https://github.com/nef1xx).

> Совсем коротко: установите Python → скачайте проект кнопкой **Code → Download ZIP** → распакуйте ZIP → дважды нажмите `start.bat`.

## Установка и запуск на Windows — инструкция

Ниже описан самый простой способ запуска на Windows 10 или Windows 11. Знать программирование, пользоваться командной строкой или разбираться в GitHub не требуется.

### Что понадобится

- Компьютер с Windows 10/11.
- Доступ в интернет при первом запуске.
- Python версии 3.9 или новее.
- Свободное место: минимум 300 МБ для работы программы и дополнительное место для готовых видео. Для спокойной работы лучше иметь несколько свободных гигабайт.

Отдельно устанавливать Git, GitHub Desktop, Node.js и FFmpeg не нужно. Аккаунт GitHub тоже не требуется.

### Шаг 1. Скачайте программу с GitHub

1. Откройте страницу проекта: [github.com/nef1xx/narezki](https://github.com/nef1xx/narezki).
2. Нажмите зелёную кнопку **Code** над списком файлов.
3. В открывшемся меню нажмите **Download ZIP**. Это обычное скачивание архива; команды `git clone`, форки и регистрация на GitHub не нужны.
4. Дождитесь загрузки файла. Обычно он появится в папке **Загрузки** и будет называться примерно `narezki-main.zip`.

### Шаг 2. Распакуйте архив

1. Откройте папку **Загрузки**.
2. Нажмите правой кнопкой мыши на `narezki-main.zip`.
3. Выберите **Извлечь всё…**.
4. Укажите удобную папку, например `Документы\Cliproom`, и нажмите **Извлечь**.
5. Откройте получившуюся папку. Внутри должны быть файлы `start.bat`, `app.py`, `engine.py` и папка `static`.

Важно: не запускайте `start.bat` прямо из окна ZIP-архива. Сначала обязательно извлеките все файлы в обычную папку.

### Шаг 3. Установите Python

Если Python уже установлен, можно сразу перейти к проверке ниже.

1. Откройте официальную страницу [Python для Windows](https://www.python.org/downloads/windows/).
2. Скачайте рекомендуемый **Python install manager** или актуальный **Windows installer (64-bit)**. Для большинства обычных компьютеров подходит вариант 64-bit.
3. Запустите скачанный установщик.
4. Если установщик показывает пункт **Add Python to PATH** или **Add python.exe to PATH**, обязательно включите его.
5. Завершите установку. После этого закройте и заново откройте Проводник и окна командной строки, если они были открыты.

Чтобы проверить установку:

1. Нажмите `Win + R`.
2. Введите `cmd` и нажмите Enter.
3. В появившемся чёрном окне введите:

```text
python --version
```

Если всё в порядке, появится строка наподобие `Python 3.13.7`. Подойдёт любая версия от 3.9 и новее. Если Windows пишет, что команда не найдена, смотрите раздел «Решение проблем» ниже.

### Шаг 4. Запустите Cliproom

1. Вернитесь в распакованную папку программы.
2. Дважды нажмите файл **start.bat**.
3. Откроется чёрное окно. Не закрывайте его — через него работает локальный сервер программы.
4. При первом запуске Cliproom автоматически скачает переносимый FFmpeg, проверит контрольную сумму и положит необходимые файлы в папку `.tools`. Это может занять несколько минут в зависимости от скорости интернета.
5. После запуска в браузере автоматически откроется адрес [http://127.0.0.1:8765](http://127.0.0.1:8765).

Адрес `127.0.0.1` означает «этот компьютер». Видео не загружаются на сторонний сайт или в облако: программа читает их с вашего диска и обрабатывает локально.

### Как запускать программу в следующий раз

Повторно скачивать и устанавливать ничего не нужно. Откройте папку Cliproom и снова дважды нажмите **start.bat**. FFmpeg при следующих запусках уже не скачивается.

### Как правильно закрыть программу

1. Дождитесь завершения экспорта или нажмите **Остановить** в интерфейсе.
2. Закройте вкладку Cliproom в браузере.
3. Перейдите в чёрное окно программы и нажмите `Ctrl + C`. После этого окно можно закрыть.

Закрытие только вкладки браузера не останавливает программу — пока чёрное окно открыто, локальный сервер продолжает работать.

## Первый клип: быстрый пошаговый пример

1. В блоке **Исходное видео** нажмите **Выбрать видео** и укажите запись стрима или другое длинное видео.
2. Если нужна короткая затравка, в блоке **Bait-ролик** выберите отдельное видео и оставьте ползунками подходящие 3–5 секунд. Этот шаг необязателен.
3. В блоке **Рекламный баннер** выберите рекламный видеоролик. Для экспорта он обязателен.
4. В разделе **Монтаж по времени** при необходимости уберите ненужное начало, конец или один фрагмент из середины основного видео.
5. В разделе **Компоновка кадра** выделите мышью область вебки, затем область основного контента.
6. Настройте текст, его размер и высоту. Все изменения сразу видны в вертикальном предпросмотре справа.
7. Нажмите **Проверить видео со звуком**, чтобы сначала создать короткую пробу. Это помогает проверить громкость, положение рекламы, bait и текст без полного экспорта.
8. Если результат устраивает, нажмите **Создать клипы**.
9. После завершения нажмите **Открыть папку результата**. По умолчанию готовые файлы находятся в папке `exports` внутри Cliproom; папку сохранения можно изменить перед экспортом.

Исходные видео программа не обрезает и не перезаписывает. Все изменения применяются только к новым экспортированным MP4-файлам.

## Решение частых проблем

### `Python не найден` или `python is not recognized`

- Перезагрузите компьютер после установки Python и снова запустите `start.bat`.
- Если не помогло, переустановите Python и включите пункт **Add Python to PATH**, если он показан установщиком.
- Убедитесь, что Python скачан с официального сайта, а не как исходный код или embeddable-пакет.

### Чёрное окно сразу закрылось

1. Откройте папку Cliproom.
2. Нажмите на адресную строку Проводника, введите `cmd` и нажмите Enter.
3. В открывшемся окне выполните:

```text
start.bat
```

Теперь сообщение об ошибке останется на экране. Его можно сфотографировать или скопировать для обращения за помощью.

### Браузер не открылся автоматически

Не закрывая чёрное окно, вручную откройте Chrome, Edge или другой браузер и введите в адресную строку:

```text
http://127.0.0.1:8765
```

### Появилось сообщение, что порт 8765 занят

Скорее всего, Cliproom уже запущен в другом окне. Сначала попробуйте открыть [http://127.0.0.1:8765](http://127.0.0.1:8765). Если страница не открывается, запустите программу на другом порту из командной строки в папке Cliproom:

```text
python app.py --port 8766 --open
```

После этого используйте адрес `http://127.0.0.1:8766`.

### Не скачивается FFmpeg

- Проверьте интернет-соединение.
- Закройте программу и повторно запустите `start.bat`.
- Убедитесь, что антивирус или корпоративный брандмауэр не блокирует доступ Python к интернету.
- Не отключайте защиту Windows целиком. Если файл был скачан не из [официального репозитория](https://github.com/nef1xx/narezki), удалите его и скачайте проект заново по ссылке выше.

### Видео не выбирается или не открывается

- Убедитесь, что файл не был удалён, переименован или перемещён.
- Раскройте **Открыть по пути к файлу**, вставьте полный путь к видео и выберите его назначение: исходник, bait или баннер.
- Для первого теста лучше использовать обычные MP4-файлы.

### Экспорт остановился из-за нехватки места

Освободите место на диске или нажмите **Изменить** рядом с папкой сохранения и выберите другой диск. Готовые ролики могут занимать больше места, чем исходное видео, особенно в режиме «Максимально быстро».

## Ручной запуск для опытных пользователей

Обычным пользователям этот раздел не нужен. Вместо `start.bat` приложение можно запустить из PowerShell или командной строки:

```powershell
python app.py --open
```

Запуск на другом порту:

```powershell
python app.py --port 8766 --open
```

## Работа

1. Выберите исходное видео. Если диалог не открывается, раскройте «Открыть по пути к файлу» и вставьте полный путь.
2. При желании выберите **bait-ролик** — короткую затравку, которая будет проигрываться перед каждым готовым клипом. Укажите нужные начало и конец (обычно 3–5 секунд) и выберите заполнение вертикального кадра или вписывание целиком. Bait можно в любой момент убрать.
3. Выберите рекламный ролик. Приложение запоминает его расположение; держите этот файл на прежнем месте.
4. В разделе «Монтаж по времени» обрежьте начало и/или конец основного видео. При необходимости включите «Вырезать фрагмент из середины» и задайте границы удаляемого участка. Нарезка на 60-секундные части выполняется уже после этих операций.
5. Нажмите «Вебка» и обведите область лица на кадре. Затем нажмите «Контент» и выделите нужную область. Предполагается, что вебка уже находится внутри исходного видео, а её позиция постоянна.
6. При необходимости выберите другой кадр ползунком. Координаты также можно задать числами, без мыши.
7. Настройте высоту вебки и режимы: **crop** заполняет область с обрезкой по центру; **fit** сохраняет всю выделенную область, добавляя чёрные поля.
8. Для текста можно отдельно настроить размер и высоту — вертикальное положение центра надписи от 5 до 95% кадра.
9. Выберите разрешение и скорость. По умолчанию — 720 × 1280, 30 кадров/с, быстрый CPU-экспорт. Режим «Максимально быстро» создаёт более объёмные файлы.
10. При желании нажмите «Проверить видео со звуком»: приложение создаст короткий образец с bait-роликом и настоящей рекламной вставкой. Это действие запускается только пользователем.
11. Нажмите «Создать клипы». Результаты появятся в отдельной папке внутри `exports` либо выбранной вами папки. Их можно воспроизвести, скачать или открыть в Проводнике.

## Длительность и реклама

- Каждая полная часть содержит **60 секунд оставленного основного видео**, а bait и реклама добавляются сверх этой минуты.
- Bait-ролик с выбранным пользователем диапазоном ставится первым в каждой части, сохраняет свой звук и приводится к вертикальному кадру в режиме `crop` или `fit`. Текст основного макета на bait не накладывается.
- Обрезка краёв и удаление внутреннего фрагмента не изменяют исходный файл. Если 60-секундная часть пересекает вырезанный участок, монтаж продолжается с первого кадра после него без пустоты.
- Например, баннер на 8 секунд даёт клип **30 секунд исходника → 8 секунд рекламы → 30 секунд исходника = 68 секунд**.
- На рекламе исходное видео и исходный звук не проигрываются. Продолжение начинается с того же места, где закончилась первая половина.
- Последняя часть содержит остаток; реклама встаёт в его середину. На границах возможна дискретность в один кадр (1/30 секунды).
- Реклама накладывается поверх стоп-кадра, сохраняя свой звук. Положение выбирается пресетами «Сверху», «Посередине», «Снизу», координатами центра X/Y в процентах или перетаскиванием рамки в предпросмотре. Баннер остаётся внутри кадра; положение сохраняется и применяется к пробному ролику и экспорту. Рамка служит только для настройки. В режиме «Вписать целиком» вокруг баннера видно исходный кадр, без добавленных чёрных полей. Режим заполнения обрезает баннер до его области. Отсутствующая аудиодорожка заменяется тишиной.
- Между вебкой и контентом можно добавить две строки текста: белую и жёлтую, с наклоном, обводкой и тенью. Размер и вертикальное положение регулируются; пустые строки скрываются. Текст сохраняется в настройках и присутствует в предпросмотре и экспорте основного видео, в том числе во время рекламы.
- Результат: MP4, H.264, yuv420p, AAC stereo 48 кГц, faststart.

## Хранение и ограничения MVP

- `data/settings.json`: пути к баннеру и bait-ролику, расположение экспорта, монтажные границы и настройки компоновки.
- `data/frames`: уменьшенные кадры для редактора; `data/previews`: пробные ролики. Их можно удалить при закрытом приложении.
- В каждой папке экспорта находятся ролики, параметры проекта и журнал FFmpeg. Исходные файлы не изменяются.
- Одновременно выполняется один экспорт. Кнопка остановки сохраняет уже готовые клипы и удаляет незаконченный файл текущей части.
- Список заданий хранится до перезапуска сервера. Экспортированные файлы остаются на диске. Автоматического возобновления прерванной очереди пока нет.
- Настройки областей постоянны на всём видео: автоматического отслеживания лица, определения сцен и отдельного источника вебки в MVP нет.
- Скорость зависит от разрешения исходника, процессора и диска. Аппаратное кодирование GPU пока не добавлено.
- Интернет требуется только для первоначального скачивания FFmpeg. Сервер слушает только `127.0.0.1`.

Сборка FFmpeg: [Gyan](https://www.gyan.dev/ffmpeg/builds/), указана на [странице загрузки FFmpeg](https://ffmpeg.org/download.html). Принцип обработки: [фильтры FFmpeg](https://ffmpeg.org/ffmpeg-filters.html).

Для обновления проверены синтаксис Python/JavaScript, интерфейс в браузере на широком и узком экране, монтажный план с вырезанным фрагментом и короткие экспорты с bait-роликом, текстом, рекламой и звуком.
